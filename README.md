# StepUp English — תוכנת לימוד אנגלית אופליין

## מה חדש בגרסה 1.4.1
- תיקון חוסר השמע בחלק מערכי המילון: נוספו הקלטות MP3 מובנות לכל 284 ערכי המילון.
- ההגייה של מילים אינה תלויה עוד בכך שמותקן במחשב קול אנגלי מקומי.
- 7 רמות לימוד ו־46 שיעורים, מהאלפבית ועד רמת Proficiency.
- שלב מעבר מדורג בין אוצר מילים למשפטים: צירופים, משפטים בסיסיים, הרחבות, שאלות, שלילה ודיאלוגים.
- שלוש רמות מתקדמות חדשות: Upper Intermediate, Advanced ו־Proficiency — 8 שיעורים בכל רמה.
- 460 שאלות ייעודיות: 10 לכל שיעור, עם שיוך לנושא ולשיעור.
- מבחן שיעור, מבחן רמה, מבחן מסכם ומבחן מיקום שממליץ על רמת פתיחה.
- 240 דוגמאות משפטים דו־לשוניות, תרגול בניית משפטים ממילים מעורבבות ותרגול הקראה.
- טקסטי קריאה והבנה ברמות המתקדמות.
- ממשק מלא בעברית ובכיווניות RTL, שמירת התקדמות מקומית וגיבוי/שחזור.

## הפעלה במחשב
גרסת Windows היא תוכנה בחלון עצמאי באמצעות Microsoft WebView2, ולא דף שנפתח בחלון דפדפן. היא נבנית ב־GitHub Actions ומופצת כ־EXE. נדרש Microsoft Edge WebView2 Runtime (כלול ב־Windows 11 וברוב מחשבי Windows 10).

## אפליקציית Android
האפליקציה נפתחת כאפליקציה עצמאית. מתאימה ל־Android 6.0 (API 23) ומעלה. התוכן הלימודי, קובצי השמע וההתקדמות המקומית נארזים/נשמרים במכשיר.

## עבודה ללא אינטרנט והגייה
אין צורך בחשבון משתמש או בשירות ענן. ההתקדמות נשמרת מקומית וניתן לייצא ולשחזר גיבוי.
לכל 284 ערכי המילון יש קובץ MP3 מובנה בתוך התוכנה והאפליקציה, כך שגם ללא קול אנגלי מותקן במערכת אפשר לשמוע כל מילה. כאשר קיים קול אנגלי מקומי מתאים, התוכנה משתמשת בו; אחרת היא משמיעה את קובץ הגיבוי המובנה.
הקראת משפטי הדוגמה והטקסטים החדשים משתמשת בקול האנגלי המקומי של המכשיר, ולכן זמינותה תלויה בקול כזה שמותקן במערכת.

## בדיקות אוטומטיות בגרסה 1.4.1
הבדיקות מאמתות 46 מסכי שיעור, 7 רמות, 284 ערכי מילון, קובץ MP3 תקין לכל אחד מערכי המילון, 460 שאלות ייעודיות, שיוך שאלות לנושא, מבחני שיעור ורמה, מבחן מסכם, מבחן מיקום, 240 דוגמאות משפטים, תרגול בניית משפטים ותחביר JavaScript. בנוסף, בדיקת השמע מדמה מחשב ללא קול אנגלי מקומי ומוודאת שכל 284 המילים מגיעות לקובץ MP3 פנימי.
בדיקת Android באמולטור מתבצעת בנפרד מבדיקת הבנייה והחתימה; הצלחת בנייה לבדה אינה נחשבת להוכחת הפעלה.

## גיבוי והתקדמות
ההתקדמות נשמרת במכשיר או בפרופיל הדפדפן המקומי. כדי להעביר אותה למכשיר אחר, השתמשו במסך ההגדרות לייצוא נתונים ולאחר מכן לשחזור מגיבוי.
