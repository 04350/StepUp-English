# StepUp English — תוכנת לימוד אנגלית אופליין

**גרסה נוכחית:** 1.4.3  
**מאגר:** https://github.com/04350/StepUp-English

StepUp English היא סביבת לימוד עצמאית לדוברי עברית, עם גרסת Windows וגרסת Android. השיעורים, המילון והקלטות המילים נארזים מקומית; ההתקדמות נשמרת במכשיר.

## מה כוללת התוכנה

- 7 רמות לימוד ו־46 שיעורים, מהאותיות ועד Proficiency.
- 284 ערכי מילון עם קובצי MP3 מובנים.
- 460 שאלות ייעודיות, מבחני שיעור ורמה, מבחן מסכם ומבחן מיקום.
- 240 משפטים דו־לשוניים, תרגול בניית משפטים ותרגול קריאה והבנה.
- תרגול יומי קצר של 10 מילים שטרם סומנו כידועות.
- מעקב התקדמות, רצף למידה וייצוא/שחזור גיבוי.

## עבודה אופליין והגייה

אין צורך בחשבון או בשרת חיצוני. כל 284 מילות המילון כוללות קובץ MP3 מובנה, ולכן השמעתן אינה תלויה בקול אנגלי שמותקן במחשב או בטלפון. הקראת משפטים חדשים משתמשת בקול אנגלי מקומי במכשיר כאשר הוא זמין; היא אינה מורידה קולות מהאינטרנט.

## גיבוי והעברת התקדמות

במסך ההגדרות אפשר לייצא קובץ JSON ולשחזר אותו בפלטפורמה השנייה. הייבוא בודק את מבנה הנתונים לפני החלפת ההתקדמות הקיימת, ותומך גם בקובצי גיבוי ישנים בפורמט 1 וגם בפורמט 2 החדש.

מומלץ לשמור עותק גיבוי מחוץ למכשיר לפני עדכון גדול או מעבר בין התקנות.

## הפעלה במחשב

גרסת Windows נפתחת בחלון עצמאי באמצעות Microsoft Edge WebView2. נדרש Microsoft Edge WebView2 Runtime (כלול ב־Windows 11 וברוב מחשבי Windows 10). לאחר התקנת הרכיב, התוכנה פועלת ללא אינטרנט.

## אפליקציית Android

האפליקציה עצמאית, מתאימה ל־Android 6.0 (API 23) ומעלה, ואינה דורשת הרשאת אינטרנט לצורך הלמידה. ההתקדמות נשמרת מקומית.

## פיתוח, גרסאות ובדיקות

- מקור האמת למספר הגרסה ול־Android versionCode הוא `version.json`.
- קובצי הבנייה מוזרקים עם מספר הגרסה בזמן יצירת ההתקנה.
- בדיקות התוכן מאמתות שיעורים, מילון, שאלות, שמע MP3, משפטים ובניית משפטים.
- בדיקות שחרור מוודאות שתיעוד וארטיפקטים משתמשים באותה גרסה.
- תהליך השחרור המרכזי מפרסם APK ו־EXE יחד ורק לאחר ששתי הבניות והבדיקות הצליחו.
- פרסום APK ציבורי מחייב מפתח חתימה קבוע. ראו [הנחיות חתימת Android](android/SIGNING.md).
