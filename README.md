# StepUp English — תוכנת לימוד אנגלית אופליין

## הפעלה
1. חלצו את תיקיית `StepUp-English` למחשב.
2. פתחו את `index.html` בדפדפן Chrome / Edge / Firefox.
3. אין צורך בהתקנה, בהרשמה או בחיבור לאינטרנט.

## מה כלול
- ממשק מלא בעברית ובכיווניות RTL.
- ארבע רמות: מתחילים, יסודות, ביניים ומתקדמים.
- 16 שיעורים מדורגים מהאלפבית ועד הבנת הנקרא, זמנים ואוצר מילים מתקדם.
- הקלטות הגייה באנגלית הכלולות בתוך `index.html` — אינן נטענות מהאינטרנט.
- כרטיסיות תרגול לאותיות, לתנועות ולמילים שימושיות.
- מבחנים עם משוב, ציון והיסטוריית תוצאות.
- שמירת התקדמות מקומית בדפדפן באמצעות localStorage.
- ייצוא ושחזור קובץ גיבוי.

## פרטיות ועבודה ללא רשת
האפליקציה אינה כוללת קוד שמבצע בקשות רשת, אינה משתמשת בשירותי ענן, אינה כוללת ספריות חיצוניות ואינה דורשת הרשאות. ההקלטות מוטמעות בקובץ HTML. ההתקדמות נשמרת רק בפרופיל הדפדפן המקומי שבו פתחתם את הקובץ. כדי להעביר התקדמות למחשב אחר, השתמשו ב'הגדרות' > 'ייצוא נתונים' ובמחשב השני ב'שחזור מגיבוי'.

## הגייה
היישום משתמש קודם בקולות אנגלית מקומיים שמותקנים במחשב דרך מנגנון הדיבור של הדפדפן. כאשר קיים קול אנגלי מקומי, הוא מקריא אותיות, מילים ומשפטים בקול המותקן במחשב — ללא חיבור לאינטרנט. במסך 'הגדרות' אפשר לבחור קול, לשמוע דוגמה ולהפעיל הגייה איטית. אם לא מותקן במחשב קול אנגלי מקומי, היישום משמיע את הקלטות הגיבוי המובנות בקובץ.

ב-Windows, אם לא מופיע קול אנגלי ברשימה, יש להתקין חבילת דיבור באנגלית דרך הגדרות Windows > זמן ושפה > שפה ואזור > English > אפשרויות שפה > Speech, ואז לפתוח מחדש את הדפדפן. שמות המסכים עשויים להשתנות מעט בין גרסאות Windows.

## בדיקות
נבדקו: תחביר JavaScript, קיום 130 התאמות בין טקסטים להקראה ובין הקלטות גיבוי, בחירת קול מקומי, השמעת דוגמת מילה ואות בבדיקת הרצה מבודדת, קיום כל 16 השיעורים ו-4 הרמות, וקובץ ZIP תקין. סריקת הקוד לא מצאה בקשות רשת, כתובות אינטרנט או תלויות חיצוניות. בדיקת קול פיזית תלויה בקולות שמותקנים במחשב שבו פותחים את התוכנה.
