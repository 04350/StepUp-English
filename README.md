# StepUp English — תוכנת לימוד אנגלית אופליין

## הפעלה
1. חלצו את תיקיית `StepUp-English` למחשב.
2. פתחו את `index.html` בדפדפן Chrome / Edge / Firefox.
3. אין צורך בהתקנה, בהרשמה או בחיבור לאינטרנט.

## מה כלול
- מילון של 158 ערכים עם תרגום לעברית.
- 9 ביטויים שימושיים עם תרגום לעברית וכרטיסיות תרגול.
- 16 מבחנים ייעודיים לשיעורים — 10 שאלות במאגר לכל שיעור.
- ממשק מלא בעברית ובכיווניות RTL.
- ארבע רמות: מתחילים, יסודות, ביניים ומתקדמים.
- 16 שיעורים מדורגים מהאלפבית ועד הבנת הנקרא, זמנים ואוצר מילים מתקדם.
- הקלטות הגייה באנגלית הכלולות בתוך `index.html` — אינן נטענות מהאינטרנט.
- כרטיסיות תרגול לאותיות, לתנועות, למילים, לביטויים ולמשפטים.
- מבחנים עם משוב, ציון והיסטוריית תוצאות.
- שמירת התקדמות מקומית בדפדפן באמצעות localStorage.
- ייצוא ושחזור קובץ גיבוי.

## פרטיות ועבודה ללא רשת
האפליקציה אינה כוללת קוד שמבצע בקשות רשת, אינה משתמשת בשירותי ענן, אינה כוללת ספריות חיצוניות ואינה דורשת הרשאות. ההקלטות מוטמעות בקובץ HTML. ההתקדמות נשמרת רק בפרופיל הדפדפן המקומי שבו פתחתם את הקובץ. כדי להעביר התקדמות למחשב אחר, השתמשו ב'הגדרות' > 'ייצוא נתונים' ובמחשב השני ב'שחזור מגיבוי'.

## הגייה
היישום משתמש קודם בקולות אנגלית מקומיים שמותקנים במחשב דרך מנגנון הדיבור של הדפדפן. כאשר קיים קול אנגלי מקומי, הוא מקריא אותיות, מילים ומשפטים בקול המותקן במחשב — ללא חיבור לאינטרנט. במסך 'הגדרות' אפשר לבחור קול, לשמוע דוגמה ולהפעיל הגייה איטית. אם לא מותקן במחשב קול אנגלי מקומי, היישום משמיע את הקלטות הגיבוי המובנות בקובץ.

ב-Windows, אם לא מופיע קול אנגלי ברשימה, יש להתקין חבילת דיבור באנגלית דרך הגדרות Windows > זמן ושפה > שפה ואזור > English > אפשרויות שפה > Speech, ואז לפתוח מחדש את הדפדפן. שמות המסכים עשויים להשתנות מעט בין גרסאות Windows.

## בדיקות
נבדקו אוטומטית: תרגום לכל 158 הערכים, תרגומי 9 הביטויים, התאמת כל מילת שיעור למילון, 26 דוגמאות האותיות, תקינות 160 שאלות ייעודיות ו-48 שאלות חזרה, הצגת כל 16 מסכי השיעורים, מבחן שיעור, מבחני רמה, מבחן מסכם וחבילת טעויות. בדיקת קול פיזית תלויה בקול אנגלי מקומי שמותקן במכשיר. סריקת הקוד לא מצאה בקשות רשת, כתובות אינטרנט או תלויות חיצוניות. בדיקת קול פיזית תלויה בקולות שמותקנים במחשב שבו פותחים את התוכנה.

## גרסת Windows כתוכנה בחלון עצמאי

בתיקיית `desktop/` נמצא קוד המקור של יישום Windows. הוא פותח חלון StepUp עצמאי באמצעות Microsoft WebView2, ולא מפעיל דפדפן חיצוני.

- קובץ היישום נבנה ב־GitHub Actions: **Actions → Build StepUp English desktop app**.
- התוצר מתקבל כ־`StepUp-English.exe` בארטיפקט `StepUp-English-Windows-x64`.
- נדרש Microsoft Edge WebView2 Runtime. הוא כלול ב־Windows 11 וברוב מחשבי Windows 10; במחשב שאין בו את הרכיב נדרשת התקנה חד־פעמית.
- כל שיעורי התוכנה, הנתונים והקלטות הגיבוי מוטמעים בקובץ EXE. התוכנה עצמה פועלת ללא אינטרנט.

## אפליקציית Android (APK)

בתיקיית `android/` נמצא פרויקט Android של StepUp English.

- האפליקציה נפתחת כאפליקציה עצמאית, ולא כדף בדפדפן חיצוני.
- מתאימה ל־Android 6.0 (API 23) ומעלה. גרסת האפליקציה הנוכחית: 1.3.2.
- קובץ הלימוד המלא והקלטות הגיבוי נארזים בתוך ה־APK, ולכן השיעורים אינם זקוקים לאינטרנט.
- ההתקדמות וההגדרות נשמרות מקומית במכשיר.
- שחזור גיבוי נתמך דרך בוחר הקבצים של Android; ייצוא גיבוי נשמר בתיקיית Downloads.
- אין הרשאת INTERNET במניפסט של האפליקציה.

### הורדת APK

ב־GitHub: **Actions → Build StepUp English Android APK → Artifacts → StepUp-English-Android**.

הקובץ נבנה כ־APK חתום לצורך התקנה ידנית. החתימה היא חתימת debug אוטומטית, ולא חתימת הפצה לחנות Google Play.
